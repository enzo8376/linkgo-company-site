# 馬上到 LINKGO 公司介紹網站

## 本版本重點
- 以公司介紹與品牌信任為主軸。
- 配送員招募資訊集中在單一專區。
- 每張真實照片只使用一次，不重複排列。
- 支援 iPhone、Android、平板及桌面瀏覽器。

## GitHub Pages 部署

1. 解壓縮部署包。
2. 將下列內容全部上傳到 GitHub repository 根目錄：
   - `index.html`
   - `README.md`
   - `assets` 資料夾
3. 進入 Repository 的 `Settings`。
4. 點選左側 `Pages`。
5. Source 選擇 `Deploy from a branch`。
6. Branch 選擇 `main`。
7. Folder 選擇 `/ (root)`。
8. 按下 `Save`，等待 GitHub 產生公開網址。

## 重要提醒
不可只上傳 `index.html`，必須同時上傳 `assets/images`，照片才會顯示。
