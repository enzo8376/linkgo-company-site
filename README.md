# 馬上到 LINKGO｜同步響應式招募網站

## 本版導流流程
網站中的「立即報名」「查看報名流程」與「查看加入方式」會統一帶到頁面最下方的報名流程。

正式報名只有兩個外部入口：

1. 先填寫 Google 報名表單。
2. 表單送出後，再加入官方 LINE，並輸入「姓名＋電話」。

這樣招募人員可快速核對表單與 LINE 身分，安排後續聯繫。

## 內容同步
手機、平板與電腦使用同一份 `index.html`，所有工作內容、報酬、時間、照片及報名流程完全一致，只調整排版方式。

## GitHub Pages 部署
1. 解壓縮 ZIP。
2. 將 `index.html`、`README.md`、`assets` 全部上傳到 Repository 根目錄。
3. 進入 `Settings` → `Pages`。
4. Source 選 `Deploy from a branch`。
5. Branch 選 `main`。
6. Folder 選 `/ (root)`。
7. 按 `Save`。

## 更新網站
上傳新版檔案並按 `Commit changes` 後，GitHub Pages 會自動重新部署。
