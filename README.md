# 馬上到 LINKGO｜同步響應式網站

## 內容同步原則
本網站只有一份 `index.html`，不是手機版與電腦版各一份。

所有裝置顯示的內容完全一致，包括：
- 蝦皮智取店店到宅服務說明
- 配送範圍與工作流程
- 取件時間與運配送時間
- 正式／兼職配送員報酬
- 加入條件
- 電動三輪車方案
- 公司資訊
- Google 表單與官方 LINE

不同裝置只會改變：
- 單欄或雙欄排列
- 圖片寬度與比例
- 卡片間距
- 導覽列顯示方式
- 浮動「立即加入」按鈕位置

手機版不會刪除或縮減任何資訊。

## GitHub Pages 部署
1. 解壓縮 ZIP。
2. 將 `index.html`、`README.md`、`assets` 全部上傳到 Repository 根目錄。
3. 進入 `Settings` → `Pages`。
4. Source 選 `Deploy from a branch`。
5. Branch 選 `main`。
6. Folder 選 `/ (root)`。
7. 按 `Save`。

## 注意
必須連同 `assets/images` 一起上傳，否則照片不會顯示。
